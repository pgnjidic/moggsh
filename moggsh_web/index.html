Vibe coding means long sessions — you and an AI, back and forth, building something real. The problem: on Android, every SSH app collapses the moment you need to read output and type at the same time.

moggsh is designed specifically for this loop. Claude generates code. You read it in the top pane. You run it in the bottom pane. The keyboard never hides anything. The joystick keeps navigation instant. The mic keeps your hands free.

  • Output locked in view — keyboard doesn't push content up
  • Joystick controls for arrow keys, Esc, Tab without switching keyboards
  • Mic button for voice commands when you're too lazy to type
  • tmux detection reattaches your session in one tap

Why moggsh

Other SSH apps weren't built
for vibe coding sessions

ERROR: usability.critical
Keyboard pushes terminal output off screen when you type
FIXED: split-view

Output zone is locked. Keyboard opens below the input field. Read Claude's response and type your next command simultaneously.

ERROR: session.lost
SSH drops and your running process is gone
FIXED: keep-alive + tmux

Foreground service keeps SSH alive. On reconnect, tmux detection offers one-tap session reattach. Nothing lost.

ERROR: ux.friction
Constant keyboard switching to hit Esc, Tab, arrow keys
FIXED: joystick bar

Permanent d-pad, Esc, Tab, Ctrl+C row — always visible, never interrupts typing flow. Navigate vim, tmux, htop with one thumb.
